# Bilingual CV sources

- `CV_EN.tex`: English engineering-oriented CV (billryan style).
- `CV_CN.tex`: Simplified Chinese translation.
- `resume.cls`: compact, font-file-free adaptation of the MIT-licensed [billryan/resume](https://github.com/billryan/resume) class.

Compile with XeLaTeX. The repository's existing Jekyll GitHub Actions workflow compiles both PDFs, copies them to `assets/CV.pdf` and `assets/CV_CN.pdf`, commits updated PDFs back to `main`, and deploys the website. Do not upload proprietary font files.

Important: English degree title and contact phone follow the owner's previously public 2025 CV. Check the official diploma wording before formal application.
